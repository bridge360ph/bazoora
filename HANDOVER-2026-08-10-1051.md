## 9. Gotchas & Lessons Learned

- **Never put backticks in a `gh ... -f body="..."` string** — bash executes them as command substitution and silently eats the terms. **Always use a heredoc with a quoted delimiter**: `gh api ... --input - << 'EOF'` (JSON) or `gh pr comment N --body "$(cat <<'EOF' ... EOF)"`. One review got garbled this way and had to be reposted.
- **CLAUDE.md / Bridge360 policy: NO AI-attribution in commits or PR bodies.** Do not add `Co-Authored-By: Claude` or "Generated with Claude Code". Strip the default trailers.
- **Review tone is warm, senior-to-junior, no "po"** (that's the interns' honorific toward the senior; the user reversing it looks wrong). Start reviews with genuine praise; frame changes as collaborative.
- **The recurring `_test` migration**: `packages/db/prisma/migrations/20260701141948_test/` (a throwaway `CREATE TABLE "Test"`) keeps riding along on branches cut from an old base — flag `git rm` it every time it appears.
- **Recurring stray edits**: PRs often show trailing-newline-only diffs to `packages/ui/src/{Button,StatCard,StatusBadge}.tsx` — those are the shared library (owned via #40); tell authors to `git checkout origin/development -- <files>` to revert.
- **Never hand-edit `pnpm-lock.yaml`** on conflict — `git checkout origin/development -- pnpm-lock.yaml && pnpm install`.
- **Prisma 7 specifics**: driver adapters are GA (no `previewFeatures` flag); datasource `url` must be in `prisma.config.ts`, not the schema; `prisma migrate diff --from-empty --to-schema <path> --script` generates a migration with no DB (set a dummy `DATABASE_URL` so the config loads).
- **Security review lesson**: when approving backend PRs, scan the **auth/authz logic** (fail-open defaults, missing ownership checks, CORS), not just whether it builds — #49 shipped 2 CRITICAL auth bypasses that gates didn't catch.
- **Self-approve merges** may be blocked by the harness auto-mode classifier ("only approval is the agent's own"); when blocked, ask the user to run the merge or confirm.
